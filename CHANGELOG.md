# Changelog

All notable changes follow Keep a Changelog conventions. Versions use Semantic Versioning.

## [1.0.0] - 2026-08-17

### Added

- offline standard and scientific calculator;
- smart contextual percentages, DEG/RAD and `Ans`;
- memory and local 50-entry history;
- English/Russian localization and accessibility support;
- light, dark and system themes;
- compact-height layout for Android 6 class devices;
- unit, instrumented and release smoke verification;
- strict lint/compiler gates, R8, CI and secure environment signing.
